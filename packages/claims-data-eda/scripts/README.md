# ⚙️ Claims Data EDA Scripts

**Utility scripts for the Claims Data EDA package.**

</div>

---

## Structure

| Path | Contents |
|:---|:---|
| [`eda/`](eda/) | EDA generation scripts |
| `eda/generate_figures.py` | Static figure generation |
| `eda/generate_interactive.py` | Interactive chart generation |

## Usage

```bash
cd packages/claims-data-eda

# Generate all figures
python scripts/eda/generate_figures.py

# Generate interactive charts
python scripts/gen_interactive_charts.py
```

## Related Files

- `reports/` — Generated reports and figures
