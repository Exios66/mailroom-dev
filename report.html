What changed

Rebuilt from 30ff6874 (was df7dea6a, 32 commits behind). The previous graph mixed tests, notebooks, and vendored OpenRouter skill scripts into 2,022 unlabeled nodes — communities were named after conftest.py and resolve-model.ts, which made the map a hairball.

This build indexes production src/ only (108 files) so the map follows the live architecture: insurance-claim specialist, intake clerk, HF docclass pilot, API /v1, unknown-type routing, Hub CUAD/MAUD inventories, and Langfuse batching/env/release alignment. Tests, notebooks, and .opencode/skills are excluded on purpose.
